TEEB on Cloudflare Pages - see the step-by-step in the chat. In short:
1. Create a free Cloudflare account. 2. Workers & Pages > Create > Pages > Upload assets > drag in teeb-cloudflare.zip.
3. Project > Settings > Bindings > Add > Workers AI > variable name AI. 4. Upload the same zip again (Deployments > Create deployment).
5. Open your .pages.dev link, log in with MEGA, tick "Reset TEEB to the built-in version" once.
